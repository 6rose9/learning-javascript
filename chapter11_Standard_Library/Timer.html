What is Process?

A process is a running instance of a program. It includes its own memory space, variables, and resources.

What is thread?

A thread is the smallest unit of execution within a process. It represents a single sequence of instructions that can be executed independently by a CPU. A process can have one or more threads running at the same time. These threads share the same memory space of the process, but each thread has its own execution stack (which keeps track of method calls, local variables, etc.). In the context of programming, threads are used to perform multiple operations concurrently, allowing for better resource utilization and more responsive programs.

What is Multithreading?

Multithreading allows a program to perform multiple operations at once (concurrently) by splitting the task into multiple threads. Each thread can execute independently, but they still share the same memory and resources. For example:In a web server, one thread could handle incoming requests, while another thread processes data, and yet another handles logging.

Single-threaded vs. Multi-threaded

Single-threaded: The program runs one instruction at a time. If one task takes too long (e.g., reading a file), the entire program might freeze until it's done.

Multi-threaded: Multiple tasks can run simultaneously. For example, in a multi-core CPU, each thread can run on a different core, executing in parallel, improving performance.

Use in JavaScript

JavaScript is single-threaded by default, meaning it executes one command at a time in sequence. However, JavaScript can handle asynchronous tasks (like I/O operations, API calls) without blocking the main thread using mechanisms like the event loop and Web Workers, which simulate concurrency.

Think of a process as a factory, and each thread is like a worker in that factory. If you have only one worker (a single thread), that worker has to do all the jobs, one by one. But if you add more workers (multiple threads), they can handle different tasks at the same time, speeding up production.

What the Event Loop?

The event loop is a mechanism that constantly checks:

  • Is the call stack empty?
  • Are there callbacks waiting in the queue?

If the stack is empty, it takes the next callback from the queue and runs it.

What setTimeout?

setTimeout is a Web API (in browsers) or a Node.js API.

It tells the environment: “After X milliseconds, run this callback.”

Call Stack (JavaScript meaning)

In JavaScript, when we say “stack”, we usually mean the call stack.
