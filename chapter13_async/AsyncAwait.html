A function declared with the async keyword always returns a Promise, regardless of what you return inside it.

  • function declaration → Heap
  • function execution → Call Stack
  • promise resolution (.then) → Microtask Queue
Note: await only works inside an async function.
  • async makes the function return a Promise
  • await pauses execution until the Promise resolves
