IndexedDB

  • Client-side NoSQL database in the browser
  • Stores large amounts of structured data
  • Asynchronous (non-blocking)
  • Data stored as key-value pairs (objects, not just strings)
  • Supports indexes for fast searching (query)
  • Same-Origin policy applies

What IndexedDB actually is

It’s a built-in storage engine inside the browser

  • No server
  • No installation
  • Works locally on user’s device

Is IndexedDB secure?

  • ✔️ Same-Origin Policy → only your domain can access it
  • ✔️ Not sent over network automatically (unlike cookies)
  • ✔️ Good for storing non-sensitive large data

Can IndexedDB be used for cache?

  • Cache API responses (so app works offline)
  • Store large JSON data
  • Save user progress (offline-first apps)
  • Cache-first strategy

IndexedDB Lifetime

IndexedDB data is persistent

  • page reload
  • tab close
  • browser restart

Removed only when:

  • user clears browser data
  • your app deletes it
  • browser clears storage (rare, low disk, privacy mode)

What is Dexie?

Using Dexie makes IndexedDB way easier. It is a wrapper library for IndexedDB.

  • Cleaner syntax
  • Promise-based (no messy events)
  • Much closer to how you’d expect a database to feel
