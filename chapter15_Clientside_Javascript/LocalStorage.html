Local Storage

  • Accessible only within the same origin (protocol, domain, port)
  • Persistent storage (no expiration, survives reloads & browser restarts)
  • Must be cleared manually (JavaScript or browser settings)
  • Stores data as key–value pairs (values are strings)
  • Storage limit ~5–10MB (varies by browser)
  • ⚠️ Not secure — avoid storing sensitive data (XSS risk)
