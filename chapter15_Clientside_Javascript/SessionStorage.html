Session Storage

  • Accessible only within the same origin (protocol, domain, port)
  • Data persists only for the duration of the page session (tab)
  • Cleared automatically when the tab or browser is closed
  • Stores data as key–value pairs (values are strings)
  • Storage limit ~5MB (varies by browser)
  • ⚠️ Not secure — avoid storing sensitive data (XSS risk)
  • Same origin + same tab → data is accessible ✔️
  • Same origin + different tab → data is NOT shared ❌
