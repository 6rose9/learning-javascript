multiplication

            101₂ = 1×2² + 0×2¹ + 1×2⁰ = 4 + 0 + 1 = 5

Decimal → Any base

division by the target base

            5 ÷ 2 = 2 remainder 1
            2 ÷ 2 = 1 remainder 0
            1 ÷ 2 = 0 remainder 1

Read remainders from bottom to top

| → “bit level OR”

|| → “condition OR”

        console.log(5 | 3); // 7
        console.log(5 || 3); // 5
