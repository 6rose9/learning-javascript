for

can mutate array, full control

for of

array is still mutable — but for...of doesn’t give you direct access to modify it.

item should be "const" instead of "let" to prevent accidental reassignment

            for...of only works with iterables
            Examples of iterables:

            ✅ Arrays
            ✅ Strings
            ✅ Maps
            ✅ Sets

            But a plain object:
            let obj = { a: 1, b: 2 }; ❌ is not iterable

            ✅ How to use for...of with objects (correct way)

            You need to convert the object into something iterable:
            1. Object.keys()
            2. Object.values()
            3. Object.entries()
🔥 If you want to mutate using modern style, Use array.map()

arr = arr.map(item => item * 2);

.map() is not for objects, it’s specifically for arrays.

forEach → just loop (no return)

for...in → works directly on objects ✅
