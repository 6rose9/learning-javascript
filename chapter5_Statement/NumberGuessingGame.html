Algorithm: Guess Random Number (1–10)

  1. Generate a random number between 1 and 10
  2. Ask the user to guess a number
  3. Read user input → guess
  4. Compare:
    1. If guess == randomNumber → Print "Correct! You guessed it."
    2. Else if guess < randomNumber → Print "Too low! Try again."
    3. Else → Print "Too high! Try again."
  5. Repeat steps 2–4 until the user guesses correctly
