use strict

  • to indicate that the code follows (in the script or function) is strict code.
  • to prevent language bad.
  1. with statement is not allowed
  2. all variables must be declared
  3. functions invoked as functions => 'this' value is undefined.
  4. assignments to nonwritable properties => throw a TypeError
  5. attempts to create new properties on non-extensible objects => throw a TypeError.
  6. code passed to eval() cannot declare variables or define functions
  7. arguments becomes a static copy => No synchronization between parameters and arguments
  8. SyntaxError is thrown if the delete operator is followed by an unqualified identifier
  9. an attempt to delete a nonconfigurable property throws a TypeError
  10. a syntax error for a function declaration to have two or more parameters with the same name
  11. eval and arguments are special identifiers => cannot use them like normal variable names
  12. octal integer 0-7 literals (beginning with a 0 that is not followed by an x) are not allowed
  13. inspect how a function was called using call stack (execution chain) => blocked.

    arguments.callee → refers to the current function

    arguments.caller → refers to the function that called it (non-standard)

    function.caller → who called this function
