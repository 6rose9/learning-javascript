Array.map()

  • You have an array
  • You want to change every item in it
  • You do not want to mutate the original array
  • Transform values
  • Extract a property from an array of objects
  • Does NOT work on plain objects
  • Use Object.keys / values / entries to map objects
  • Map (JS type) ≠ Array.map()
want to change every element and get a new array.

Map()

  • Built-in data structure used to store key–value pairs, similar to an object
  • Keys that are not just strings
  • Keys can be string, number, boolean, object, function
  • Fast lookup and frequent add/remove
  • Want ordered key–value data
  • Cleaner handling of dynamic data
