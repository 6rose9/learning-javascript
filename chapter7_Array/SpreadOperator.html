What is shadow clone object?

Creating a new object by copying only the top-level object, while nested objects are not copied and are shared by reference.

  • Only the top-level object is copied
  • Nested objects still point to the same memory
  • Changes to inner data affect both copies
### sperator opterator is shadow clone.

What is Deep clone object?

A deep clone makes a fully independent copy of the object.

  • The object and all nested objects are copied
  • No shared references
  • Changes in one do not affect the other
### JSON.stringifying is deep clone.
