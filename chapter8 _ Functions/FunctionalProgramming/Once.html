Imperative Programming

You tell the computer how to do something, step by step.

Key characteristics:
  • Uses statements that change program state
  • Relies on variables, assignments, and loops
  • Focuses on control flow (if, for, while)

Functional Programming

You tell the computer what to do, not how to do it.

Key characteristics:
  • Uses functions as the main building blocks
  • Immutability (avoids changing state)
  • No side effects (same input → same output)
  • Uses expressions instead of statements
  • Relies on recursion instead of loops
